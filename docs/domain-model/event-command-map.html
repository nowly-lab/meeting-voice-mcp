操作から出来事へ

（リードモデルを見て）アクター（またはポリシー） → コマンド → 集約・外部システム → イベント。集約は一緒に更新しないと整合性が崩れるデータのまとまりで、その下にいつでも守るルール（不変条件）を並べています。

だれがコマンド集約・外部システムイベント証拠
録音
会議のエージェント(Claude)録音を始める会議
  • 録音中の会議は1台に1つ(録音中に始めようとしたら、録音中の会議を示して断る)
  • 発言の通し番号は会議の中で増えるだけ
  • Mac の音の許可がなくてもマイクだけで続ける
  • 発言は書いた順に utterances.jsonl へ追記し、書き換えない

  • スピーカーの音をマイクが拾った発言(3秒以内の相手側とほぼ同じ文字)は自分側から外し、外した印を残す
  • 取り込みが遅れて保存できなかった音声は、側と時間の範囲を「音声の欠け」として会議に残し、画面と状態に出す

  • 発言はちょうど1つの区切りに入る
  • 閉じた区切りの中身は変わらない
  • 区切りの番号は会議の中で1から順に増える

  • 受け取ったまま30秒届かなければ、また受け取れる
  • 届いたことを記録した区切りは二度と届けない

出来事から次の操作へ

イベント → ポリシー（実行方式） → コマンド。ポリシーは、イベントが起きたときに次に何をするかを決めるルールです。人が判断するときはアクターをはさみます。
